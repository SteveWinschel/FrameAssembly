# FrameAssembly Architecture & Language Guidelines

- **6-Stage Zero-Copy Compiler Pipeline + Reverse Decompiler**: Maintain strict separation across:
  1. **Lexical Analysis (`src/lexer/mod.rs`)**: Zero-copy `logos 0.14.4` DFA scanner emitting `(Token<'a>, Range<usize>)` slices with strict-lowercase built-in keywords (`[a-z0-9]+`, zero `_`, zero `-`, no `ignore(ascii_case)`) and flexible user-defined identifiers (`[a-zA-Z_][a-zA-Z0-9_]*(-[a-zA-Z0-9_]+)*`).
  2. **Two-Phase Parsing (`src/parser/`)**: `winnow 1.0.5` combinators over `Stream<'i, 'a> = &'i [(Token<'a>, Range<usize>, &'a str)]` using `parse_universal_field` -> `dispatch_protocol_field` -> explicit protocol-keyword disambiguation when `current_protocol.is_none()` (preventing BACnet `whois` from shadowing `Protocol::Whois`) -> `parse_fallback_field`, plus self-healing diagnostics suggesting `replace '<raw>' with '<kw>'`.
  3. **Semantic Validation (`src/parser/validation.rs`)**: `validate_semantics(&program, &source)` enforcing symbol uniqueness, flow arity, IPv4/IPv6 endpoint homogeneity, L2 MAC-only vs IP-required protocol checks (`protocol_requires_ip`), field bounds (such as unified `hellotime <= 255` on `hsrp`), and modifier exclusivity.
  4. **Native Inner-Outward Wire Builders (`src/builders/`, `src/packet.rs`)**: `L7 -> L4 -> L3 -> MPLS/QinQ/VLAN/Ethernet II` framing, case-insensitive `_`/`-`-normalized enum string matching, RFC 1071 / SCTP `CRC32c` / DNP3 `CRC-16` checksums, ASN.1 BER/DER, and SNMPv3 USM crypto.
  5. **Stateful 4-Tuple & Dynamic Dispatch (`src/backend/`)**: Evaluates `compile` (`RunStatement::{Invocation, Frame}` — `loop` removed in v2.0.0), tracks `EndpointPairPorts` and `Canonical4Tuple` TCP sequence state, and honors `L7DispatchResult`.
  6. **Transactional Nanosecond PCAPNG Emission (`src/pcap.rs`) & Reverse PCAP Decompiler (`src/reverse/`)**: Buffers all `(Vec<u8>, u64)` frames in memory before writing `SHB -> IDB (ETHERNET, snaplen 65535, IfTsResol(9)) -> EPBs`, and supports reverse PCAP/PCAPNG-to-`.fasm` decompilation (`reverse_pcap_reader(reader)`, `reverse_pcap_bytes(bytes)`, `reverse_pcap_file(path)` across `src/reverse/{l2,l3,l4,l7}/<protocol>.rs`) emitting `host1`, `host2` (zero `_`), strict-lowercase `[a-z0-9]+` tokens, direct flow invocations in `compile` (never `loop`), per-packet self-check oracle verification, and zero `//` warning/fallback comments.
- **Strict-Lowercase Keywords vs. Flexible Identifiers (v2.0.0)**:
  - Every built-in keyword, protocol, modifier, and time unit (`ns`, `us`, `ms`, `s`, `m`) is **strictly lowercase alphanumeric (`[a-z0-9]+`) with zero `_` and zero `-`** (100% mechanical `_` removal: `echorequest`, `innervlan`, `clienthello`, `hosthdr`, `transporthdr`, `sackperm`, `agentip`, `hellotime`, `whois`, `pkttype`, `read`, `write`, `nop`, `error`, `shutdownack`, `readholdingregisters`, etc.), paired with self-healing compiler diagnostics suggesting `replace '<raw>' with '<kw>'` on v1/uppercase/`_`/`-` typos and clear migration guidance on removed `loop` blocks.
  - User-defined `host`, `flow`, and parameter names remain flexible (allowing uppercase, `_`, and `-` via `[a-zA-Z_][a-zA-Z0-9_]*(-[a-zA-Z0-9_]+)*`), and quoted protocol enum values (`qtype "a"` or `"A"`) plus pasted MAC/IPv6/hex literals match flexibly while `reverse`, docs, and examples emit lowercase.
- **Expose Protocol Fields & Wire Completeness**: Never hardcode protocol parameters (e.g., SNMPv3 `engineboots`, `enginetime`, `contextname`). Expose them as optional `.fasm` modifiers and wire every AST `*Spec` field parsed in `src/parser/` into `src/builders/`.
- **L7 Builder Return-Tuple Preservation (`src/backend/l7_dispatch.rs`)**: Always preserve dynamic `L7DispatchResult` ports and multicast IPs—`dhcp` (`68/67` v4 vs `546/547` v6), `mdns` (`224.0.0.251` / `ff02::fb` on UDP `5353`), `ptp` (`319` Event vs `320` General), and `radius` (`1812` Auth vs `1813` Accounting, swapping onto `src_port` on `<-` replies).
- **Minimal Canonical Keyword Surface & Dual-Stack Reuse**: Keep keywords concise for network technicians—use `ip` for both IPv4 and IPv6 in `host`, `ttl` and `dscp` across IPv4/IPv6 (never `hoplimit`, `tos`, or `trafficclass`), and silently ignore IPv6 `flowlabel` when a flow executes over IPv4 hosts. Mixing IPv4 and IPv6 endpoints in a single statement is strictly forbidden.
- **Smart RFC Defaults & Modern Standards**: Derive RFC-compliant defaults automatically when omitted (`01:00:5e:xx:xx:xx` RFC 1112 IPv4 multicast MACs, `33:33:xx:xx:xx:xx` RFC 2464 IPv6 multicast MACs, `ttl 255` on `ndp`/`vrrp`/IPv6 `arp`, `0.0.0.0` SNMPv1 `agent-addr` over IPv6 per RFC 3584, RFC 7860 SNMPv3 SHA-2, RFC 5798 VRRPv3 pseudo-header checksums, RFC 9000 §16 QUIC 2-byte varints).
- **CLI Contract (v2.0.0 Default-Compile + 4 Subcommands)**: Compiling `.fasm` to `.pcap` is the default root command: `frameassembly <input.fasm> [output.pcap]` (defaults to `<input_stem>.pcap`—there is **no** `compile` CLI subcommand), paired with strictly 4 subcommands: `frameassembly show <input.fasm>` (validates and prints a relative-timestamp packet ladder table without writing disk files), `frameassembly reverse <input.pcap> [output.fasm]` (defaults to `<input_stem>.fasm`, decompiling `.pcap`/`.pcapng` into canonical `.fasm`), `frameassembly help [subcommand]`, and `frameassembly version` (no `-o`/`--output` flags; `-h`/`--help` and `-V`/`--version` hidden for script compatibility; `check_legacy_cli_args` rejects `-o`/`--output`, `--show`/`--reverse`, bare `.pcap` at arg 1, accidental `"compile"` as arg 1, and `.fasm` as `OUTPUT.pcap`; Tab-completion scripts in `contrib/completions/`).
- **Private User Context Confidentiality**: Never include private background context shared by the user in prompts (such as employer names or employment status) anywhere in code, comments, examples, documentation, or metadata.
- **One-Word Branding, `.fasm` (`text/vnd.frameassembly`) Disambiguation & Companion Role**:
  - Always write `FrameAssembly` as one CamelCase word (`frameassembly` for crate/CLI/npm/URLs)—never split `Frame` and `Assembly` with a space.
  - Disambiguate FrameAssembly `.fasm` (`text/vnd.frameassembly`, TextMate scope `source.frameassembly`) from x86 Flat Assembler (`;` comments, `format PE`/`ELF`) and FPGA FASM (`#` comments, tile bit paths).
  - Position FrameAssembly as the upstream companion compiler to `Wireshark`, `tshark`, `tcpreplay`, `Suricata`, `Zeek`, and `Snort` (compare only against packet generators: `Scapy`, `text2pcap`, `Ostinato`). Describe it as `"rootless"`, `"offline"`, `"deterministic"`, and `"no libpcap or raw sockets required"`—never claim `"zero external crate dependencies"`.
- **6-Way Grammar, Lexer, IDE, WASM & Docs Lockstep**: Keep `src/lexer/mod.rs` <-> `src/parser/` <-> `grammar.ebnf` <-> `frameassembly.gbnf` <-> `frameassembly.lark` <-> `frameassembly-vscode/syntaxes/frameassembly.tmLanguage.json` in 100% lockstep, and synchronize `frameassembly-wasm`, `README.md`, `src/lib.rs`, `docs/fasm-specification.md`, `llms.txt`, `llms-full.txt`, `contrib/mime/text-vnd.frameassembly.xml`, `contrib/linguist/heuristics.yml`, and `docs/*.md`.
- **Audience Separation, Natural Voice & Scoping of `"DSL"` Jargon**:
  - **User-Facing Networking Docs (`README.md`, `frameassembly-vscode/README.md`, and `docs/*.md` except `docs/for_nerds.md`)**: Written for network/security technicians in a natural, direct human voice using practical tool examples (`Checkmk`, `Zabbix`, `Wireshark`, `Suricata`, `tcpreplay`). Never spam empty AI adjectives (`"readable"`, `"clean"`, `"editable"`, `"canonical"`, `"repeatable"`), never parrot repetitive feature slogans (`"no root"`, `"without sudo, libpcap, or raw sockets"`, `"unprivileged user space"`, `"no programming experience required"`), never use compiler/PL jargon (`"DSL"`, `"Domain-Specific Language"`, `"declarative"`, `"polymorphic"`, `"AST"`, `"token slice"`), never call `.fasm` `"plain text"` (always call it `.fasm` **code**), and never leak user prompt phrasing or meta-headings into prose.
  - **Developer, Crate & AI Metadata (`Cargo.toml`, `src/lib.rs`, `docs/for_nerds.md`, `frameassembly-wasm/README.md`, `llms.txt`, `llms-full.txt`, `context7.json`, `codemeta.json`, `CITATION.cff`)**: Technical terms (`DSL`, `AST`, `RLVR`, `EBNF`/`GBNF`/`Lark`) are permitted for developer/crate/AI indexing.
- **Canonical Syntax Only (Anti-Hallucination Ban List)**:
  - `host <id> { [ip <ip>] [mac <mac>] }` (at least one of `ip` or `mac` is required; pure L2 protocols `lldp`, `stp`, `lacp`, `eapol`, `vlan`, `qinq`, `mpls`, `arp` support MAC-only hosts via `protocol_requires_ip`, while L3/L4/L7 protocols require `ip`; `mac` accepts `00:1a:2b:3c:4d:5e`, `00-1A-2B-3C-4D-5E`, `001a.2b3c.4d5e`; never `=`, `:`, `,`, `/24` CIDR, `ipv4`, `ipv6`, or `mask`).
  - `flow <id>(<params>) { <a> -> <b> <proto> ... [wait <u32><ns|us|ms|s|m>] }` (never parameterless `flow id { ... }`, `from`/`to`, `send`, standalone `wait` lines, `+5ms`/`[+delay]`, `;`, `#` comments, `'single quotes'`, `sport`/`dport`, `ack <n>` instead of `acknum <n>`, `host` for `hosthdr`, `transport` for RTSP `transporthdr`, or `loop`).
  - `compile { <flow>(<hosts>) | <a> -> <b> <proto> ... }` (exactly one `compile` block per file supporting `RunStatement::{Invocation, Frame}`; `loop` is removed in v2.0.0; never argumentless flow calls).
- **1 Statement = 1 Frame & 81 Native Protocols**: Every statement emits 1 Ethernet frame; TCP L7 statements share 4-tuple `seq`/`acknum` state (`seq = 1000`, `psh ack`) with raw `tcp`. Native coverage spans all 81 protocols:
  - **L2 (8)**: `arp`, `vlan`, `qinq`, `lldp`, `stp`, `lacp`, `eapol`, `mpls`.
  - **L3 (20)**: `icmp`, `ndp`, `igmp`, `mld`, `gre`, `vxlan`, `geneve`, `ipsec`, `esp`, `ah`, `ikev2`, `wireguard`, `ospf`, `bgp`, `rip`, `vrrp`, `hsrp`, `pim`, `bfd`, `openflow`.
  - **L4 (3)**: `tcp`, `udp`, `sctp` (plus `transport tcp|udp` on `modbus`, `nfs`, `memcached`, `dnp3`, `ethernetip`, `dns`, `sip`, `syslog`, `kerberos`).
  - **L7 (50)**: `snmp1`, `snmp2`, `snmp3`, `dns`, `mdns`, `dhcp`, `ntp`, `ptp`, `radius`, `tacacs`, `syslog`, `netflow`, `ipfix`, `sflow`, `tftp`, `ftp`, `ssh`, `telnet`, `http`, `http2`, `grpc`, `websocket`, `tls`, `quic`, `stun`, `sip`, `rtp`, `rtsp`, `smtp`, `imap`, `pop3`, `kerberos`, `ldap`, `smb`, `nfs`, `redis`, `memcached`, `mysql`, `postgres`, `mqtt`, `coap`, `amqp`, `ssdp`, `whois`, `modbus`, `bacnet`, `dnp3`, `s7comm`, `ethernetip`, `opcua`.
