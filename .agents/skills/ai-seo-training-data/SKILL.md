## 4. 6-Way Constrained Decoding, IDE & WASM Lockstep Rules (v3.0.0)

FrameAssembly v3.0.0 enforces a **6-way strict-lowercase (`[a-z0-9]+`, zero `_`, zero `-`, no `loop`) synchronization invariant**:
1. **`src/lexer/mod.rs` & `src/parser/`**: Ground-truth Rust tokenizer (`#[token("host")]`, `#[token("echorequest")]`, `#[token("innervlan")]`, `#[token("hosthdr")]`, `#[token("sackperm")]`, `#[token("agentip")]`, `#[token("hellotime")]`, `#[token("whois")]`, `#[token("pkttype")]`, `#[token("read")]`, `#[token("write")]`, `#[token("nop")]`, `#[token("error")]`, `#[token("shutdownack")]` — zero `ignore(ascii_case)`, zero `Token::Loop`), flexible user `Token::Ident` (`[a-zA-Z_][a-zA-Z0-9_]*(-[a-zA-Z0-9_]+)*`), and self-healing diagnostics (`replace '<raw>' with '<kw>'`).
2. **`grammar.ebnf` (ISO/IEC 14977 EBNF)**: Every RHS non-terminal must be defined on the LHS, every terminal keyword is strict lowercase without `_` or `-`, and `run_statement = flow_invocation | frame_statement` (`loop` removed).
3. **`frameassembly.gbnf` (`llama.cpp` & MLC-AI `XGrammar` GBNF)**: Starts with `root ::= ...`, zero left recursion, defines every referenced rule, includes `"report"` in `snmp-proto-field` (`"get" | "getnext" | "response" | "set" | "trap" | "getbulk" | "inform" | "report"`), and omits `loop`.
4. **`frameassembly.lark` (`llguidance` & `Outlines` Lark CFG)**: Uses `start:` and `%ignore`. Because Earley/LALR lexers prioritize literal keyword terminals over `IDENT`, `str_or_ident` **must** union `IDENT | STRING` with contextual **lowercase** keyword tokens (`"cname"`, `"text"`, `"init"`, `"data"`, `"ack"`, `"sync"`, `"report"`, etc.) so valid constructs like `encoding cname` or `chunk init` are never rejected.
5. **`frameassembly-vscode/syntaxes/frameassembly.tmLanguage.json` (VS Code TextMate Grammar)**: Scope `source.frameassembly` (never `source.fasm`), highlighting all 81 strict-lowercase protocol keywords, L2–L7 modifiers, `wait <int><ns|us|ms|s|m>`, and `host`/`flow`/`compile` blocks.
6. **`frameassembly-wasm` & `frameassembly-vscode` (In-Process WASM Packet Studio)**: `validate_fasm` (accurate `compile`-block backend error spans + preserved `help` hints powering VS Code 1-click Quick Fix `CodeActionProvider`), `inspect_fasm` (enriched `PacketPreview` with `source_dest`, `protocol`, `summary` powering the live Packet Ladder `WebviewPanel`), `compile_fasm_to_pcapng`, and Explorer `.pcap`/`.pcapng` `Reverse to .frasm`.

### Specific Grammar Audit Bugs to Prevent & Fix in QA
1. **Undefined Non-Terminal in `grammar.ebnf`**: Always define `string_char`, `escape_sequence`, `letter`, `digit`, `hex_digit`, `hex_byte`, `hex_word`, `ipv4_address`, `ipv6_address`.
2. **Overly Restricted `type` and `chunk` Rules**: Generic `type` and `chunk` rules across EBNF, GBNF, and Lark must accept `unsigned_int`, `str_or_ident`, and protocol-specific tokens matching `src/parser/`.
3. **Missing `"report"` in SNMP Protocol Field**: Include `"report"` alongside `"get"`, `"getnext"`, `"response"`, `"set"`, `"trap"`, `"getbulk"`, and `"inform"`.
4. **Lark Contextual Keyword Collision in `str_or_ident`**: Union contextual lowercase keywords in `str_or_ident` so `llguidance` / `Outlines` Earley/LALR lexing accepts unquoted lowercase keyword values (`encoding cname`, `chunk init`).

## 5. Multi-Task SFT, FIM, DPO & 4-Stage RLVR Compiler-Reward Architecture

### 5.1 Five-Task Synthetic Dataset Export (`2,611` `.frasm` Scenarios $\rightarrow$ `13,055` Instances)
From `examples/**/*.frasm` (`2,611` strict-lowercase v3.0.0 scenarios: `31` per protocol across 81 protocols + `100` topologies), dataset exporters synthesize **13,055 training instances** across 5 tasks (with an **MLCommons Croissant 1.0 `croissant.json`** manifest):
1. **Task 1 — Forward SFT (`2,611` pairs)**: Maps `// PROMPT:` to strict-lowercase `.frasm` code using `// TOKENS:` and `// INSTRUCTION:` reasoning.
2. **Task 2 — Repo-Level & File-Level FIM (`2,611` triplets)**: Uses `<|repo_name|>`, `<|file_sep|>`, `<|fim_prefix|>`, `<|fim_suffix|>`, and `<|fim_middle|>` to synthesize `flow` bodies from `host` and `compile` context.
3. **Task 3 — Inverse PCAP-to-`.frasm` Decompilation (`2,611` pairs via `src/reverse/`)**: Pairs deterministic PCAP/PCAPNG captures with `src/reverse/` output (`host1`, `host2`, strict lowercase without `_`, direct flow calls in `compile` with zero `loop` folding).
4. **Task 4 — Contrastive DPO Preference Triplets (`2,611` triplets)**: Mutates valid `.frasm` ASTs with common hallucinations (`+5ms` delays, standalone `wait`, uppercase/underscore v1.x keywords like `HOST` or `INNER_VLAN`, removed `loop` blocks, `sport`/`dport`, mixed IPv4/IPv6) into `(prompt, chosen_valid_fasm, rejected_invalid_fasm)` pairs.
5. **Task 5 — Execution-Feedback Self-Repair & RLVR Trajectories (`2,611` trajectories)**: Pairs mutated programs and self-healing `miette` diagnostics (`replace '<raw>' with '<kw>'`) with repaired v3.0.0 `.frasm` code.

### 5.2 4-Stage Hierarchical RLVR Reward Function ($R(x, y) \in [0.0, 1.0]$)
FrameAssembly provides a `< 1 ms` deterministic 4-stage additive reward function (`+0.15` + `+0.25` + `+0.30` + `+0.30` = `1.0`):
- **Stage 1 — Lexical Validity (`+0.15`, $R = 0.15$)**: `frameassembly::lexer::lex(y)` tokenizes with zero `CompilerError::LexError` spans.
- **Stage 2 — Syntactic AST Validity (`+0.25`, $R = 0.40$)**: Syntactic parsing (`parse_all` / `parse_program(y)` without `CompilerError::ParseError`) produces a valid `Program` AST (`host`, parameterized `flow`, `compile`).
- **Stage 3 — Semantic & Dual-Stack Type Validity (`+0.30`, $R = 0.70$)**: `frameassembly::parser::validate_semantics(&program, y)` passes with zero `CompilerError::SemanticError` violations.
- **Stage 4 — Wire Compilation & Decompilation Oracle (`+0.30`, $R = 1.0$)**: `frameassembly::backend::compile_program(&program)` emits valid Ethernet frames (`>= 14` bytes) with verified RFC checksums and passes `src/reverse/` PCAP-to-`.frasm` round-trip verification.
