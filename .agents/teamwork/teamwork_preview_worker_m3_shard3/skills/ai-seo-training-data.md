# AI Training Data & Search Engine Optimization (AI/SEO) Skill

Use this skill when structuring, documenting, packaging, or auditing open-source repositories, Rust crates, and custom Domain-Specific Languages (DSLs) so they survive automated pre-training filters, achieve high educational quality scores, and provide zero-hallucination context to AI coding assistants and search engines.

## 1. Pre-Training Pipeline & RAG Indexer Filter Matrix

| Pipeline / Indexer Stage | Quantitative Heuristic / Filter Rule | Repository Optimization Requirement | Anti-Pattern to Avoid |
| :--- | :--- | :--- | :--- |
| **The Stack v2 / StarCoder2 File Size** | Max `1,000,000` chars; max `100,000` lines | Keep source (`.rs`), example (`.fasm`), and doc (`docs/*.md`) files `< 50 KB` (`< 12K tokens`) | Monolithic multi-megabyte source files or unsplit documentation dumps |
| **The Stack v2 `.txt` 512-Line & Stem Filter** | `.txt` files dropped if `> 512` lines OR stem $\notin$ `{readme, notes, todo, description, cmakelists, *requirement*}` | Dual-home all knowledge from `llms.txt` / `llms-full.txt` into `README.md` and chunked `docs/*.md` (`Markdown` is exempt from the 512-line `.txt` filter) | Relying exclusively on `llms.txt` or `llms-full.txt` for pre-training ingestion |
| **Line-Length Heuristics (Code)** | Dropped if `avg_line_length > 100` or `max_line_length > 1,000` chars | Enforce `avg_line_length <= 85` and `max_line_length <= 200` across all `.fasm` and `.rs` files | Single-line minified blobs, unformatted tables, or 2,000-char hex strings |
| **Character Ratio Filters (Alpha / Hex)** | Dropped if alphanumeric ratio `< 0.25` OR hex character ratio `> 0.25` | Pair every hex payload or numeric OID in `.fasm` / `.rs` with descriptive natural-language comments (`// PROMPT:`, `// INSTRUCTION:`) | Raw hex dumps or unlabeled byte arrays exceeding 25% of file characters |
| **Gopher / FineWeb / Dolma Repetition** | Dropped if duplicate lines `>= 30%` or duplicate 5-grams `>= 20%` | Keep intra-file duplicate lines `< 25%` by varying hostnames, IP subnets, flow names, and assertions across tests and examples | Copy-pasting identical boilerplate setup blocks across dozens of unit tests |
| **`go-enry` / Linguist `is_generated`** | Dropped if first 5 lines match `auto-generated`, `do not edit`, `generated by` | Start `.fasm` files with `// PROMPT:` and `// TOKENS:` and `.rs` files with `//!` module docstrings | Placing `// Auto-generated file` headers in corpus examples or AST files |
| **`go-enry` Unknown Extension Filter** | Custom DSL extensions (`.fasm`) are `Unknown` in static `languages.yml` | Embed fenced ````frameassembly` and ````fasm` blocks inside `README.md`, `docs/*.md`, and Rust `///` docstrings + configure `.gitattributes` | Leaving custom DSL examples isolated only in unrecognized file extensions |
| **Qwen2.5-Coder / DeepSeek-Coder Repo Packing** | Packs repo files (`16K–32K+` window) ordered by dependency graph (`<\|repo_name\|>`, `<\|file_sep\|>`) | Add `/// Syntax mapping: \`...\`` docstrings on every AST struct/enum to bind Rust types directly to DSL syntax in the same context window | Disconnected AST types with no docstring mapping to concrete surface grammar |
| **FineWeb-Edu / LLM Quality Scorers** | Llama-3 / Qwen classifiers score educational value `0–5` (retaining `>= 3`) | Use authoritative RFC citations, architecture diagrams, wire default tables, and Q&A instruction-tuning pairs in `docs/*.md` | Self-deprecating disclaimers (*"toy project"*, *"broken prototype"*, *"hack"*) |
| **Crates.io PostgreSQL `TEXT` Ingestion** | Rejects literal NUL bytes (`0x00`) with HTTP `500 Internal Server Error` | Enforce zero `0x00` bytes across `README.md`, `docs/*.md`, `llms.txt`, and `llms-full.txt`; always escape binary signatures (`\x00`) | Raw binary bytes or unescaped NUL characters in Markdown tables or code blocks |
| **AI Coding Agents (`AGENTS.md`, `llms.txt`)** | Natively read by Cursor, Claude Code, Copilot, Windsurf, Zed, Context7 | Provide root `AGENTS.md`, curated `llms.txt` routing map, and single-fetch `llms-full.txt` payload | Missing build/test commands or unindexed documentation directories |
| **Constrained Decoding (`EBNF` / `GBNF`)** | `llama.cpp`, `vLLM`, and `Outlines` enforce token-level grammar masks | Ship root `grammar.ebnf` (ISO/IEC 14977) and `frameassembly.gbnf` (`llama.cpp` GGML BNF) covering 100% of lexer/parser rules | Informal prose-only syntax descriptions without formal grammar productions |

## 2. Multi-Layer AI & Search Engine Architecture

1. **Pre-Training Corpus Survival (Dual-Homing Strategy)**:
   - **Why Dual-Homing is Mandatory**: Software Heritage (`SWH`) archives the full Git tree, and pipelines like **The Stack v2**, **StarCoder2**, **Dolma**, **DeepSeek-Coder**, and **Qwen2.5-Coder** filter files by `go-enry` language classification and file-level heuristics. Because `.txt` files over 512 lines are dropped and custom DSL extensions (`.fasm`) are not in `go-enry`'s compiled `languages.yml`, a custom DSL repository must dual-home its grammar and examples across:
     1. **Chunked Markdown (`docs/*.md` and `README.md`)**: Classified as `Markdown`, exempt from the 512-line `.txt` filter, and heavily weighted for text-code grounding. Each file in `docs/*.md` must be strictly `< 50 KB` (`< 12K tokens`) so it is never truncated during 16K/32K chunking.
     2. **Rust Source Docstrings (`src/**/*.rs`)**: Classified as `Rust` (Tier-1 code language). Every module (`//!`) and public item (`///`) includes RFC references, `/// Syntax mapping:` annotations, and runnable `# Examples`.
     3. **Annotated DSL Corpus (`examples/<layer>/<protocol>/<protocol>_<scenario>.fasm`)**: Structured with `// PROMPT:`, `// TOKENS:`, and `// INSTRUCTION:` comments for repository-level context packing (`<|repo_name|>`, `<|file_sep|>`).
     4. **Formal Grammars (`grammar.ebnf` and `frameassembly.gbnf`)**: `grammar.ebnf` is natively recognized by GitHub Linguist / `go-enry` as `EBNF`, while `frameassembly.gbnf` enables zero-error constrained decoding in `llama.cpp`.

2. **Agentic RAG & IDE Discovery (`llms.txt`, `llms-full.txt`, `AGENTS.md`, Context7)**:
   - **`AGENTS.md`**: Acts as the "README for machines" at the repository root. Contains exact build, test, lint, and corpus verification commands, module layout invariants, and DSL design rules.
   - **`llms.txt`**: Follows the `llmstxt.org` specification (`# Title`, `> Summary`, concise architecture & syntax overview, and H2 sections containing `- [Link](url): Description` routing maps to `docs/*.md`, `grammar.ebnf`, `frameassembly.gbnf`, `src/`, and `examples/`).
   - **`llms-full.txt`**: Provides the complete, self-contained single-fetch context bundle (README + `docs/*.md` + EBNF/GBNF grammars + complete Rust AST definitions + all verified `.fasm` examples) for large-context LLMs.

3. **Search Engine, Crates.io, Docs.rs & Academic Indexing (`Cargo.toml`, `CITATION.cff`, `.gitattributes`)**:
   - **`Cargo.toml`**: Populate `description`, `repository`, `homepage`, `documentation`, `readme = "README.md"`, 5 high-value `keywords` (`pcap`, `networking`, `dsl`, `packet-crafting`, `security`), and valid `categories` (`network-programming`, `development-tools::testing`). Keep the published crate tarball lean via `exclude` (excluding `llms.txt`, `llms-full.txt`, `docs/`, `frameassembly-vscode/`, `tests/`, `.github/`, `.agents/`, `demo.fasm`, `grammar.ebnf`, `frameassembly.gbnf`, `AGENTS.md`, `CITATION.cff`).
   - **`CITATION.cff`**: Citation File Format 1.2.0 metadata at the repository root for Software Heritage, Zenodo, Google Scholar, and academic corpus harvesting.
   - **`.gitattributes`**: Map `*.fasm` and `*.ebnf` / `*.gbnf` for GitHub Linguist statistics while marking binary archives (`*.vsix`, `*.pcap`) as binary/generated.
