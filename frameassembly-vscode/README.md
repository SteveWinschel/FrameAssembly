# FrameAssembly DSL Support

Provides syntax highlighting for FrameAssembly (`.fasm`) files in Antigravity IDE and VS Code.

## Features
* Zero-copy lexer token mapping for `HOST`, `FLOW`, and `COMPILE` blocks.
* Keyword formatting for supported protocols (TCP, UDP, SNMP).
* Highlighting for IP addresses, MAC addresses, and OIDs.
